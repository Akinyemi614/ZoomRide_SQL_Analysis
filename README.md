# ZoomRide SQL Project

## Project Overview
This project analyzes ride-hailing data for ZoomRide, a fictional company that sells rides across six cities. 
The goal is to help management make better business decisions about where to invest and how to improve operations.

This project was created as part of a data analysis portfolio to demonstrate skills in database management tools and 
understanding of the structured query languages.

---
## Business Objectives
The main objective of this project is to use SQL to identify patterns in ZoomRide's operations and determine which city 
offers the best opportunity for investment.

This analysis aims to answer the following questions:
- Which city generates the highest revenue?
- Which city has the highest customer demand?
- Which month is the best (highest revenue and trip count)?
- Which vehicle type has the most demand?
- Who are the top 3 customers?
- Which city should ZoomRide consider investing in?
- What data quality issues exists in the database

---

## Key Findings
- Lagos recorded the highest revenue and Total trip count
- December has the highest revenue and trip count
- The economy vehicle recorded the highest number of trips and revenue

---
## Data Quality issues
- Duplicate records- This could distort the ride counts, customer totals or revenue calculations if not fixed
- Data inconsistencies- This could distort city level comparisons
- Missing Values: This issue could reduce the accuracy of operational reporting and total revenue and lead to incorrect
  conclusions about business performance or growth

## Recommendation
